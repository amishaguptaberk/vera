## Known limitations

- Re-evaluation on evidence change is proven through the service hook only; the evidence pipeline must call it (done when VER-004 merges).
- "Authorized" can only come from a typed callback record, which no ticket in tonight's slice produces.
- Rules for reviewer approval, credit, closure and "claims are not facts" are not in v1 data; they belong to later gates.
- No product command sets `requires_policy` yet; the stage-7 gate is tested with a test command.
- `GET /api/policies/*` needs no session.
- Receipt presence uses a status denylist; an allowlist is safer.
- `PolicyView` lacks Handoff §7.4 fields `credit_eligible`, `verify_needed`, `blocking_reason`.
- CaseView shows the latest evaluation without an explicit stale flag.
