## Known limitations

- The pill state uses `isolate: true` and its x is not asserted, because the placeholder has no role selector (prototype x 963.69 vs app 1247.67). VER-012-F1 must remove `isolate` and assert x and y against an anchor. A purely horizontal shift passes today.
- In isolate mode, context is covered by computed style, y and effective opacity, not by pixels.
- Pixel threshold is 0.05; token changes are caught mainly by exact computed-style equality (`tests/parity/ACCEPTED.md`).
- Lint gaps: `@/api/` with a trailing slash and dynamic `import()` pass; features may import design-system and lib directly. Plain `next build` skips lint, so CI must call `npm run build`.
- The DOM restore in `compare.ts` is not in try/finally.
- Several §9 values are not tokens yet (letter-spacings, some type sizes, button heights, spinner timing); they belong to the primitive slices.
- This machine has Inter installed as a system font, which could hide a broken font route; CI and dev must use the same browser and fonts.
- `src/app` may import design-system as an F0-only exception. `src/api/schema.d.ts` is a placeholder until the backend serves `/openapi.json`.
- The shifted-pill self-test was not run red against the old harness by the builder; the reviewer's mutation probes cover that gap.
