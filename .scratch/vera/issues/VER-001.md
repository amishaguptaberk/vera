Title: VER-001 — Persist and read CHG-1042

User value:
An analyst opens Cases and sees the real, persisted CHG-1042 with its amount, state, owner and due date instead of browser-local data.

Scope:
- Repository scaffold per plan §1 (Python 3.12, FastAPI service, domain package, Alembic, pytest/ruff/mypy config, dev database script, compose file).
- Baseline migration for cases, users and roles, cardholders, merchants, card_transactions, reports, claims, state_transitions, audit_events.
- Seed the canonical fixture (ToSpec §4) plus the non-openable display rows; `POST /api/demo/reset` restores it.
- `GET /api/cases`, `GET /api/cases/summary`, `GET /api/cases/{id}` returning the CaseView fields available at this stage: state, step, amount, merchant, owner, due, pins, transaction, cardholder, charge_impact, empty available_actions.
- Emit `case.created` / `report.received` once on seed; database triggers make audit_events, reports and state_transitions append-only.

Non-goals:
- Commands other than seed/reset.
- Evidence, communications, policy.
- Any frontend work.

Acceptance criteria:
- GET /api/cases/CHG-1042 returns state `reported`, step `intake`, amount 284000 cents USD, merchant Northstar Equipment, owner Sam Rivera, workflow v3, policy v1.
- Creating the same case or report twice yields one case and one report; the second attempt links to the existing case (US-A04).
- REP-1042 is stored as a claim and cannot be updated or deleted (US-A05).
- UPDATE or DELETE on audit_events fails at the database.
- Summary returns open exposure, due today, overdue and temporary credit computed from rows, not constants (US-B01).
- Reset returns the database to the seed state and is safe to repeat.
- ruff, mypy and pytest pass; the documented commands are in CONTRIBUTING.md.

Dependencies:
- None

Test-first behavior:
An integration test that resets the database, reads CHG-1042 and asserts the projection fields above; then seeds again and asserts row counts are unchanged.

Demo proof:
Reset, then curl the three read endpoints and show CHG-1042 in the queue JSON.
